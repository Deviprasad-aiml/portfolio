HOW IT WORKS

Serverless To-Do App on AWS

Follow one request through the architecture. Select a step to jump to it. CloudFront serves the page over HTTPS.

  1. Load the pageThe browser requests index.html from the S3 static website.
  2. Call the APIJavaScript fetch() sends JSON over HTTPS to the API Gateway /todos routes.
  3. Invoke LambdaAPI Gateway triggers the Python todo-handler, running under a least-privilege IAM role.
  4. Read / write dataLambda reads and writes the Todos table in DynamoDB and logs to CloudWatch for debugging.

HOW IT WORKS

Serverless Image Upload & Gallery App on AWS

Follow one image upload through the architecture. Select a step to jump to it.

  1. Load the galleryThe browser requests index.html from the S3 static website.
  2. Ask for an upload URLJavaScript sends POST /upload-url over HTTPS to API Gateway.
  3. Sign the URLThe getUploadUrl Lambda creates a presigned URL, running under a least-privilege IAM role.
  4. Upload to S3The browser sends the image straight to the images bucket using the presigned URL (CORS enabled).
  5. List & deletelistImages and deleteImage work with the DynamoDB images table and the bucket (GET /images, DELETE /images/{imageId}).
